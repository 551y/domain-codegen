# 上传演示用例（case）

用于演示「上传自己的文件」功能的现成用例，对应平台的两个知识库入口。

## 文件清单

| 文件 | 适用入口 | 内容 |
|---|---|---|
| `星务协议示例-dllg星务协议.docx` | 入口一 · 卫星协议代码生成（**推荐**） | dllg 卫星星务 CAN 总线协议文档（协议库中已有目标）。上传后走真实 LLM 生成，**评测与离线预置同一套 ground truth AST 比对体系**——平台按内容指纹自动识别该文档并挂上标准答案；因 LLM 新生成的产物与预置产物内容不同，评测缓存必然不命中，**现场真实跑一遍评测**（树编辑距离计算量大，评测阶段需等待数分钟） |
| `星务协议示例-XX3数据链CAN协议.docx` | 入口一 · 卫星协议代码生成 | 合成的 XX-3 型无人平台 CAN 总线协议：ID 分配、2 组遥测帧（信号/位段/换算公式表）、5 条遥控命令表、内部总线报文、CRC 校验与函数命名规范。无人工标准答案，评测为参照文档的覆盖度评测 |
| `模型源码示例-dronenet.py` | 入口二 · 无人机模型部署适配 | 自包含的轻量视觉骨干 DroneNet（~100 行）：深度可分离卷积 + SE 通道注意力 + 双线性上采样融合，含 12 个 torch 算子调用 |

## 使用方式

1. `./start.sh` 启动平台，打开 http://localhost:3200
2. 选择对应场景入口 → 在「或上传自己的文件」区域拖入/选择本目录下的文件
3. 点击「开始生成」

## 注意事项

- **上传文件的生成需要配置 LLM Key**（顶栏齿轮设置）：上传的输入没有预生成结果兜底，未配置 Key 时会在"生成"阶段提示失败——这是预期行为，上传与检索环节本身可正常演示
- 协议上传的评测分两种口径：**dllg 用例**有标准答案 → 与离线预置一致的 AST 比对（配置四维 + 函数匹配 + 综合加权）；**XX3 用例**无标准答案 → **参照文档的覆盖度评测**（从上传文档表格提取命令码/遥测信号/处理函数名做名称级 F1 匹配 + 字段完整性 + Handler 语法检查，无表格时回退基础结构检查）。模型用例评测为语法/导出调用/自检检查
- DroneNet 的 `F.interpolate`（双线性上采样）与 SE 模块的 sigmoid/mul 是 ONNX 导出中的典型讨论点，检索阶段会命中相关知识记录，可在「检索注入的知识」中展开查看
- 用例均为演示用合成内容，不包含真实平台数据
