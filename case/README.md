# 上传演示用例（case）

用于演示「上传自己的文件」功能的两个现成用例，对应平台的两个知识库入口。

## 文件清单

| 文件 | 适用入口 | 内容 |
|---|---|---|
| `星务协议示例-XX3数据链CAN协议.docx` | 入口一 · 卫星协议代码生成 | 合成的 XX-3 型无人平台 CAN 总线协议：ID 分配、2 组遥测帧（信号/位段/换算公式表）、5 条遥控命令表、内部总线报文、CRC 校验与函数命名规范 |
| `模型源码示例-dronenet.py` | 入口二 · 无人机模型部署适配 | 自包含的轻量视觉骨干 DroneNet（~100 行）：深度可分离卷积 + SE 通道注意力 + 双线性上采样融合，含 12 个 torch 算子调用 |

## 使用方式

1. `./start.sh` 启动平台，打开 http://localhost:3200
2. 选择对应场景入口 → 在「或上传自己的文件」区域拖入/选择本目录下的文件
3. 点击「开始生成」

## 注意事项

- **上传文件的生成需要配置 LLM Key**（顶栏齿轮设置）：上传的输入没有预生成结果兜底，未配置 Key 时会在"生成"阶段提示失败——这是预期行为，上传与检索环节本身可正常演示
- 协议用例无人工标准答案，评测为**参照文档的覆盖度评测**：从上传文档的表格中确定性提取命令码/遥测信号/处理函数名，与生成产物做名称级匹配（F1），外加字段完整性与 Handler 语法检查；文档无结构化表格时回退为基础结构检查。模型用例评测为语法/导出调用/自检检查
- DroneNet 的 `F.interpolate`（双线性上采样）与 SE 模块的 sigmoid/mul 是 ONNX 导出中的典型讨论点，检索阶段会命中相关知识记录，可在「检索注入的知识」中展开查看
- 两个用例均为演示用合成内容，不包含真实平台数据
